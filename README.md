# yourinstans

Flappy Bird MVP web game with:
- Bird physics (gravity + jump)
- Pipe obstacles and collisions
- Score + best score tracking
- Start / playing / game-over states with restart
- Login/profile cloud simulation using localStorage
- Full-screen leaderboard page
- Admin panel (code `4514`) with score management controls
- Desktop/mobile support and device selection
- Settings for sound, animations, background effects, and themes

## Run

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
